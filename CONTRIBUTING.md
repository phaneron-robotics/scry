# Contributing to Scry

Thanks for your interest. Scry is built by Phaneron Robotics, Inc.

The app (`scry-app`) and the robot-side server (`scry-connect`) live in
private repos, so the best way to help right now is **issues and
feedback on this [`scry`](https://github.com/phaneron-robotics/scry)
repo** — it's where we track everything.

## Reporting a bug

[Open an issue](https://github.com/phaneron-robotics/scry/issues/new/choose)
with:

- What you expected vs. what happened
- Steps to reproduce
- Your environment: ROS distro, OS, Scry version
  (`scry-connect --version` or the app's About screen), and AI provider

## Suggesting a feature

Open an issue describing the problem you're trying to solve, your
proposed solution (or "let's discuss"), and any alternatives you
considered.

## Security issues

Don't file these publicly — see [SECURITY.md](SECURITY.md).

## Questions

Open an issue, or email
[info@phaneronrobotics.com](mailto:info@phaneronrobotics.com).
